# 任务入口迁移说明

任务顺序采用启动加速器、启动游戏、游戏唤醒、日常、材料本、战斗、故事扫荡、故事开荒、GP任务、循环战斗、领取礼物盒。

- 原独立“强敌来袭”任务改为“战斗 → 强敌来袭”或“故事扫荡 → 强敌来袭”。战斗模式不检查略过次数，扫荡模式检查次数耗尽。
- 原独立“领取每日任务奖励”任务改为“日常 → 领取每日任务奖励”。
- “领取礼物盒”直接执行领取礼物流程。
- 原“是否略过”选项改为“是否开启自动战斗”；连续扫荡使用“故事扫荡”，普通战斗使用“战斗”。
- 角色要求通过“日常 → 角色要求”启用，不勾选时不执行。
- 活动普通扫荡通过“故事扫荡 → 活动扫荡”选择 HARD1–HARD3；完整批量扫荡通过“故事扫荡 → 活动HARD扫荡”选择 HARD1–HARD5。
- 体力包默认不启用；故事开荒和扫荡分别勾选对应选项。

升级前备份保存的任务配置。旧配置中的独立任务名和旧选项不会自动迁移，需按以上对应关系重新选择并保存。
